I) Создание курьера
1. Успешное создание курьера 
2. Нельзя создать двух одинаковых курьеров 
3. Для создания курьера требуется передать все обязательные поля 
4. При успешном создании запрос возвращает правильный код ответа 
5. Если нет одного из обязательных полей, в ответе ошибка

II) Логин курьера 
1. Курьер может авторизоваться 
2. Успешный запрос возвращает id
3. Для авторизации требуется передать все обязательные поля 
4. Возврат ошибки при авторизации с некорректными данными

III) Создание заказа 
1. При создании заказа можно указать
2. Можно указать один из цветов - BLACK or GREY 
3. Можно указать оба цвета 
4. Можно не указывать цвета 
5. Тело ответа содержит track

IV) Список заказов 
1. При запросе к ручке "Список заказов" возвращается список всех заказов
